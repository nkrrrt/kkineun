# 함께 쓰는 가계부

둘이서 함께 쓰는 수입·지출 기록장입니다.

- **화면**은 깃허브 Pages 에 올라가 있습니다 → https://nkrrrt.github.io/kkineun/
- **내역**은 구글 시트에 있습니다. 여기 저장소에는 내역이 들어오지 않습니다.
- **문지기**는 구글 로그인입니다. 시트를 공유받은 사람만 들어올 수 있습니다.

```
폰/PC  ──로그인 증명서와 함께──▶  앱스 스크립트  ──▶  구글 시트
(깃허브 Pages)                   (증명서 확인 후 명단 대조)
```

---

## 처음 한 번 해야 하는 설정

### 1. 구글 로그인 버튼 등록하기 (약 10분)

화면이 구글 주소를 벗어났기 때문에, "이 사이트에서 로그인 버튼을 쓰겠다"고
구글에 등록해야 합니다.

1. https://console.cloud.google.com 접속
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 아무거나 (예: `kkineun`) → 만들기
3. 왼쪽 메뉴 **API 및 서비스 → OAuth 동의 화면**
   - User Type: **외부** → 만들기
   - 앱 이름, 사용자 지원 이메일, 개발자 연락처 이메일 채우고 저장
   - **테스트 사용자**에 두 사람의 지메일 주소를 추가
4. 왼쪽 메뉴 **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**에 추가: `https://nkrrrt.github.io`
   - 만들기 → 나오는 **클라이언트 ID** 복사 (`...apps.googleusercontent.com`)

### 2. 앱스 스크립트 다시 배포하기

1. 구글 시트 → **확장 프로그램 → Apps Script**
2. `apps-script/Code.gs` 내용을 전부 붙여넣기
3. 맨 위 `CLIENT_ID` 에 1번에서 복사한 값을 넣기

   ```js
   var CLIENT_ID = '여기에-붙여넣기.apps.googleusercontent.com';
   ```
4. 저장 → **배포 → 새 배포 → 웹 앱**

   | 항목 | 값 |
   | --- | --- |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

   > 아무나 들어올 수 있게 여는 것처럼 보이지만 그렇지 않습니다. 창구는 열어두되,
   > 들어온 요청마다 구글 로그인 증명서를 확인하고 시트 공유 명단과 대조합니다.
   > 명단에 없으면 아무것도 돌려주지 않습니다.

5. 나오는 **웹 앱 URL** 복사 (`.../exec` 로 끝나는 것)

### 3. `config.js` 채우기

이 저장소의 `config.js` 를 열어 두 줄을 채웁니다.

```js
var CONFIG = {
  apiUrl: 'https://script.google.com/macros/s/.../exec',
  clientId: '....apps.googleusercontent.com'
};
```

> 둘 다 비밀번호가 아닙니다. 공개돼도 괜찮습니다. 문을 지키는 건 이 값이 아니라
> 구글 로그인과 시트 공유 명단입니다.

### 4. 깃허브 Pages 켜기

저장소 **Settings → Pages**

- Source: **Deploy from a branch**
- Branch: **main** / **/ (root)** → Save

1~2분 뒤 https://nkrrrt.github.io/kkineun/ 가 열립니다.

### 5. 폰에 앱으로 설치하기

크롬으로 위 주소를 열고 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

아이콘이 붙고 주소창이 사라집니다.

## 사람 초대하기

**구글 시트를 편집자로 공유하면 끝입니다.** 그게 곧 초대 명단입니다.
따로 승인할 것도, 암호를 알려줄 것도 없습니다.

빼고 싶으면 시트 공유를 해제하면 됩니다. 바로 막힙니다.

## 고친 뒤에는

**화면**(`index.html`, `app.js`, `styles.css`) — 올리면 1분쯤 뒤 자동 반영됩니다.
다만 **올리기 전에 판 번호를 올려야** 합니다. 안 그러면 폰이 옛 파일을 계속
붙들고 있어서, 고친 것이 사용자에게 안 보입니다.

```
npm run bump     # 판 번호 올리기 (잊으면 안 됨)
npm test
git push
```

지금 무슨 판이 도는지는 **설정 화면 맨 아래**에 보입니다. 고쳤는데 번호가
그대로면 옛 파일이 도는 것입니다.

**서버**(`apps-script/Code.gs`) — 이건 자동이 아닙니다. 붙여넣은 뒤
**배포 → 배포 관리 → ✏️ → 새 버전 → 배포**

## 확인하기

```
npm install     # 처음 한 번
npm test
```

서버 로직과 "화면이 실제로 열리는지"까지 확인합니다.
